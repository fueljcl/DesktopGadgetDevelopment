# DesktopGadget 1.0.0 データの取扱い

2026年10月31日版。本体、公式サイト、問い合わせの実際の取扱いを説明します。無料Marketplaceと言語パックの配布を開始しています。

## PC内に保存する情報

本体は設定、ガジェットの配置、メモ・予定、利用者が選んだ取得先や保存先、許可状態、履歴等をPC内に保存します。認証情報や保護対象の保存情報にはWindowsアカウントに結び付けた保護を使用します。すべての設定ファイルが暗号化されるわけではありません。バックアップや利用者が書き出したファイルも、利用者側で保管先・共有先を管理してください。

本体のアンインストールだけでは、設定や利用者のデータを一律に削除しません。設定を消す場合は、必要なバックアップを確保してから、アプリを終了し、案内された保存先の内容を確認して削除してください。利用者が別の場所へ保存したファイルや外部サービス上のデータは別に管理します。

## 外部へ通信する場合

本体の更新確認は公式の更新情報を取得します。起動時確認は任意で、初期状態では無効です。診断の内容やメモ・予定の本文を更新確認に添付する仕組みではありません。通信先では、通信に必要なIPアドレス等の接続情報を扱います。

外部情報の取得やAI等のサービスを有効にした場合、その機能の実行に必要な要求や利用者が選んだ内容が、設定した相手先へ送られます。有効にした機能には定期取得するものがあります。接続先・送信対象・費用を確認してください。ブラウザを開いて利用するサービスには、そのサービスやブラウザ側の取扱いも適用されます。

無料Marketplaceでは、ID、認証用の公開鍵、復旧用の検証情報、セッション、作品の提出・取得等に必要な記録を扱います。目的は認証、利用権の確認、作品の配信、運用と不正利用への対応です。PC内のメモや予定全体をMarketplaceへ同期する仕組みではありません。IDの削除はアプリの退会操作から行います。退会と公開済み作品・運用記録・バックアップの取扱いは区別します。

## 診断と問い合わせ

開発支援レポートは、利用者が内容を画面で確認してからローカルに保存します。自動送信はしません。現在のレポートは版番号、機能数、読み取り・描画の失敗数等を含み、メモ・予定本文、端末の識別情報、パス、URL、録音、認証情報を含めない設計です。レポート以外の添付や画面写真を送る場合は、内容を確認してください。

メールやDiscordで連絡した場合、送信者の連絡情報と問い合わせ・添付内容を、回答、調査、対応履歴の管理に使用します。必要な期間保管し、不要になった情報を整理します。パスワード、秘密鍵、本人確認書類を不具合報告へ添付しないでください。公開のDiscordへ投稿した情報は、他の参加者からも見える場合があります。

## 公式サイトと保管・削除

公式サイトと配信基盤にはCloudflare、メール窓口にはGoogle、コミュニティにはDiscordを利用します。アクセスや問い合わせに伴う情報は各サービスでも扱われます。公式サイトの公開ページには、独自の広告追跡・解析用スクリプトを追加していません。

アクセス制御、署名検証、Windowsの保護機能、不要な秘密情報をログに残さない対策等を用います。バックアップ等のコピーは、元データの削除と同時にすべて消えるとは限りません。削除や確認の問い合わせは下記窓口へご連絡ください。本人との関係を必要な範囲で確認し、適用される法令と実際の保存状況に応じて対応します。
