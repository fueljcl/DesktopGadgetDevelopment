# 使い始める・更新する

対象：DesktopGadget Free 1.4.0。2026年11月12日公開。

1. [公式配布ページ](https://desktopgadget.org/download/)から一般版を取得します。
2. ZIPを展開し、付属のSetupを開きます。表示される版・保存先を確認して導入します。
3. アプリを起動し、使いたいガジェットを追加します。通信やファイル読取りが必要な機能は、内容を確認して許可します。
4. 詳しい操作は、アプリのヘルプから開くHTMLマニュアルを参照してください。使用中の言語に対応した説明と画像を開けます。

## 更新

更新確認は手動で行えます。「アプリ設定」上部の更新通知を有効にすると、起動時と1時間ごとに確認します（初期状態は無効）。同じ新版は初回だけ通知し、今回の起動中の通知履歴・イベントタイムラインにも記録します。再起動しても同じ版を繰り返し通知しません。管理画面上部の更新案内は残ります。確認だけで本体を自動導入しません。更新時も正規のSetupを使います。念のため、先に大切なデータをバックアップしてください。

接続できないPCでは、別のPCで本体のZIPと最新の「持込み用安全情報」を取得し、USB等で持ち込みます。SetupでそのJSONファイルを選びます。安全情報は発行から30日有効です。期限切れなら新しいものを取得してください。安全情報の期限は、導入済みのローカル機能の通常起動期限ではありません。

## 困ったとき

エラーの文面、操作、版番号を確認し、[Discord](https://discord.gg/9Pydmv4BKx)へお知らせください。個別情報を含む場合は [メール](mailto:desktopgadget.org@gmail.com)をご利用ください。パスワードや秘密鍵は送らないでください。診断レポートは自動送信されません。

無料Marketplaceを利用できます。管理画面の「追加・拡張」からマーケットプレイスを開きます。接続済みのアカウントを自動利用し、作品を選んで「インストール／更新」を押すと追加できます。初めて使う場合はアカウントの登録・接続を行います。言語パック導入後は設定で表示言語を選び、保存して再起動してください。任意の開発支援は公式の寄付ページで受付中です。

## 1.4.0の改善

フォーチュンアドバイスを追加しました。初回に生年月日を入力し、今日のみ・向こう1週間のみ（今日から7日間）・今月のみ・一括から選べます。初期値は一括です。右クリックから表示範囲と「内容だけを表示」を変更できます。同じ版・生年月日・日付なら同じ結果です。端末内の数秘術風の計算とオリジナル文章による娯楽で、生年月日を外部へ送りません。

Windows終了時は未保存がある場合だけ保存し、追加の終了診断ファイルを書かずに終了へ追従します。起動時に複数表示がフォーカスを奪う経路を見直しました。前回の正常終了を確認できない場合も起動を止めるダイアログは出さず、管理画面で復旧を案内します。未完了・保存失敗時の保護は維持します。

## 1.3.5の改善

すべてのガジェットで「内容だけを表示」を選べるようになりました。日間・週間予定で操作順によって枠やつまみが残る問題も修正。「透明・黒文字」「透明・白文字」の2テーマを追加し、全6プリセットになりました。透明テーマでは管理画面をデフォルト配色に保ち、ガジェットを壁紙になじませます。個別の配色・透明度を優先し、テーマの元に戻す操作にも対応しています。

表示設定または右クリックで「内容だけを表示」を選びます。透明テーマとは別々に設定できます。透明テーマを個別調整済みのガジェットへ適用するには、表示設定で個別設定をリセットしてください。管理画面はデフォルト配色を保ちます。F3・背景メニュー・不透明度スライダーによる明示設定はテーマより優先します。画像や外部HTMLの内容は書き換えません。

## 1.3.4の改善

Windows終了時に保存・停止が完了済みでも待機時間超過だけで回復警告になる場合を修正しました。保存失敗や停止未完了時の保護は維持し、当時は原因確認用の終了診断記録を追加しました（1.4.0では終了時の追加書込みを削減しています）。ライトテーマの入力欄・状態表示・選択行の文字も読みやすくしました。

カレンダー・日間予定・週間予定のガジェット内に「インポート」ボタンを追加しました。表示専用時は右クリックの「インポート」、クリック透過時は管理画面を使います。管理画面で対象を選んだ右側のインポート／エクスポートも引き続き利用できます。

## 予定の共有と配色

予定や繰り返し系列を選んで、ファイルまたは一般／限定公開のMarketplaceリンクへ書き出せます。限定リンクは知っている人なら取得でき、転送も可能です。同じURLで新版を公開できますが、受け取る側で再取得し、重複時は上書き・併存・取り込まないを選びます。自動同期は行いません。

繰り返しの終了日・回数制限と、今回だけ／期間限定の変更を共有します。編集画面の確認開始日・確認終了日はプレビューの範囲で、予定の繰り返し期間ではありません。通知やカレンダー設定の適用は取り込み時に選び、ジョブ定義・実行権限・パス・アカウント情報は共有しません。

管理画面はクラシック・ライト・ピンク・ブルーの4プリセットを選べます。一括適用でも表示器の個別設定を保持し、直前のテーマへ戻せます。カーソル強調は外枠・内側の不透明度を別々に調整でき、丸形の内側を0%にすると中央が透明になります。

## 1.2の変更

管理画面を用途別の4ページに整理し、通常操作の重複した確認を減らしました。アカウントの利用権は起動時・通信復帰時・定期的に自動確認し、マーケットプレイスも同じ接続を使います。Setupでは操作を選んで実行でき、旧版の整理は削除中の項目と進捗を表示します。

UAC表示後のカーソル復帰、カレンダーの土日・祝日の色、通知ボードの保持件数・表示件数（各1～100）と表示器の高さを改善しました。起動時には.NETの読み込み前に実行ファイル群を検査します。

更新前に設定・予定データをバックアップしてください。公式ZIPは全体を展開し、旧版のファイルへ一部分だけを上書きしないでください。検査で問題が見つかった場合は公式ZIPを新しいフォルダーに展開するか、Setupの修復を使います。保存形式は27です。更新前にデータ保存フォルダーを丸ごとバックアップし、1.3.5以前へ戻すときは更新前の設定バックアップも復元してください。
