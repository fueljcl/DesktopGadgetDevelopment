# 最初の作品を作る

まずは [HelloPlugin.cs](../../samples/hello/HelloPlugin.cs) を使います。入力した文字の前に `Hello: ` を付けるだけの例です。

1. アプリで作品の制作画面を開き、種類に「Plugin」を選びます。
2. C#ソースに `HelloPlugin.cs`、出力先に新しいDLLファイルを指定してコンパイルします。DLLは、作品の処理を入れるファイルです。
3. 入口に `Example.HelloPlugin`、出力の種類にテキストを選びます。
4. 自分の発行者ID、作品ID、版、作者用の署名鍵を設定します。公式の鍵や他人の鍵は使いません。
5. ファイル一覧と説明を確認し、署名して新しいZIPへ書き出します。署名は、作者と内容の対応を確認するためのものです。
6. ZIPと対応する公開鍵を使って導入します。公開鍵の指紋（照合用の文字列）は信頼できる別の経路でも確認します。
7. 入力に `World` を指定し、内容を確認して実行を許可します。`Hello: World` が返れば成功です。

導入しただけでは実行しません。実行を終えるには停止操作を使います。変更したら版を上げ、改めて確認・署名します。鍵はサンプルや配布ZIPへ入れず、アプリの案内に従って保管します。
