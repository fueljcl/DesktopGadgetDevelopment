# 同梱した文章 / Bundled text

`BundledPlugin.cs` をアプリでコンパイルします。種類はPlugin、入口は `BundledPlugin`、出力はテキスト。素材として `message.txt` を加え、確認・署名します。実行すると入力とその文章を返します。

Compile `BundledPlugin.cs` in the app. Choose Plugin, entry `BundledPlugin`, and text output. Add `message.txt` as an asset, review and sign. Execution returns the input and bundled text.

作品内の署名された素材だけを読みます。文章を変更したら再署名してください。
Only the signed bundled asset is read. Sign again after changing the text.
