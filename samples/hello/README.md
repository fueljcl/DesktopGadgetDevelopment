# 挨拶 / Greeting

`HelloPlugin.cs` をアプリでコンパイルします。種類はPlugin、入口は `Example.HelloPlugin`、出力はテキストです。入力 `World` に対して `Hello: World` を返します。

Compile `HelloPlugin.cs` in the app. Choose Plugin, entry `Example.HelloPlugin`, and text output. Input `World` returns `Hello: World`.
